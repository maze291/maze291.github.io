# GCC Analyst Market Tracker

Public project page for GCC Analyst Market Tracker.

The site presents an overview of the project, including aggregate market metrics, dated dashboard images, methodology notes, an anonymized sample table, and the current May 2026 baseline report status.

Current status:

- 1,304 reviewed analyst-role signals across all six GCC countries.
- May 2026 baseline report layer generated locally with a May 29, 2026 data cutoff.
- Public issue #1 release remains gated on source-permission emails to JSearch / OpenWeb Ninja and Careerjet.
- Public outputs are aggregate-only; raw samples and job-level derived rows stay private.
